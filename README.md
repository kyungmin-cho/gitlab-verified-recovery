# Verified Recovery: evidence ledger

Live: https://kyungmin-cho.github.io/verified-recovery/

This is the published evidence ledger for [Verified Recovery](https://gitlab.com/gitlab-ai-hackathon/transcend-october-2026/43457157/verified-recovery), a supervised GitLab Duo flow that takes an incident to a verified recovery. The page is built from the committed recovery records in that project with `node scripts/build-evidence-viewer.mjs`; the source of truth and the CI that produces it live on GitLab.
